# سجل مهام الموظفين

صفحة واحدة توضّح مهام كل موظف، المدير الذي طلبها، المدة المتوقعة لإنجازها، وحالتها. تُفتح من الرابط مباشرة بدون تسجيل.

## الملفات

- `index.html` الصفحة كاملة.
- `config.js` إعدادات ربط مخزن البيانات المشترك (Firebase Firestore).
- `firestore.rules.example` قواعد الحماية: السجل لا يُفتح إلا برمز الدخول.

## التشغيل

1. فعّل GitHub Pages من إعدادات المستودع (الفرع `main`، المجلد الجذر).
2. أنشئ مشروع Firebase وفعّل Firestore، ثم الصق إعدادات المشروع في `config.js`.
3. الصق القواعد من `firestore.rules.example` في تبويب Rules بعد وضع رمز الدخول.

بدون الخطوتين 2 و3 تعمل الصفحة في وضع تجريبي يحفظ المهام على الجهاز نفسه فقط.

## الحساب

حجم العمل وموعد التفرّغ تقديريان: يوم العمل 8 ساعات، وأيام العمل من الأحد إلى الخميس.
